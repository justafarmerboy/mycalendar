# ปฏิทินฟ้า

เว็บแอปปฏิทินบอก **รอบวัน วิษุวัต อายัน และข้างขึ้นข้างแรม**

- โลกอยู่ตรงกลาง แกนโลกเอียง 23.4° ขั้วโลกเหนืออยู่ด้านบน โลกหมุนตามเวลาจริง (เห็นกลางวัน/กลางคืน)
- ดวงอาทิตย์อยู่ทางซ้ายตำแหน่งคงที่ ทิศที่แกนโลกเอียงจึงเปลี่ยนไปตามฤดู
  - ครีษมายัน (21–22 มิ.ย.) ขั้วโลกเหนือเอียงเข้าหาดวงอาทิตย์
  - เหมายัน (21–22 ธ.ค.) ขั้วโลกเหนือเอียงหนีดวงอาทิตย์
  - วสันตวิษุวัต (20–21 มี.ค.) / ศารทวิษุวัต (22–23 ก.ย.) แกนเอียงเข้าหา/ออกจากผู้ดู กลางวันเท่ากลางคืน
- ดวงจันทร์โคจรรอบโลกบนวงโคจร และด้านขวาแสดงดวงจันทร์ตามที่เห็นบนฟ้าจริงจากสถานที่ที่เลือก
  ด้านสว่างหันไปทางดวงอาทิตย์ และหมุนเอียงไปตามเวลา (จันทร์เสี้ยวหัวค่ำในไทยหงายเป็นรูปเรือ
  ซีกโลกใต้ข้างขึ้นสว่างด้านซ้าย) ถ้าดวงจันทร์อยู่ใต้ขอบฟ้าจะแสดงจางลง
- **มุมมองจากด้านบน (bird's-eye view)** ดวงอาทิตย์อยู่กลาง โลกโคจรทวนเข็มนาฬิกา เห็นขั้วโลกเหนือ
  แกนโลกชี้ไปทางดาวเหนือทิศเดิมตลอดปี กดปุ่ม "▶ ดูโลกโคจรครบ 1 ปี" เพื่อดูเป็นแอนิเมชัน (ประมาณ 12 วินาทีต่อปี)
- **อุปราคา** วาดเงาโลกและทางโคจรจริงของดวงจันทร์ที่เอียง 5° (ขยายให้เห็นชัด) ดวงจันทร์เป็นสีแดงเมื่อเข้าเงามืด
  การ์ดอุปราคาบอกจันทรุปราคา/สุริยุปราคาครั้งถัดไป ว่าเห็นได้จากสถานที่ที่เลือกหรือไม่ พร้อมภาพย่อส่วนจริงของทางผ่าน
- การ์ดฤดูกาลรอบปี (ธ.ค. บน · มี.ค. ขวา · มิ.ย. ล่าง · ก.ย. ซ้าย) พร้อมวันเวลาที่แน่นอนของแต่ละปี
- การ์ดรอบวัน: เวลาดวงอาทิตย์ขึ้น/ตก ความยาวกลางวัน ตามสถานที่ที่เลือก
- การ์ดดวงจันทร์: วงรอบ 8 ช่วงข้างขึ้นข้างแรม ขึ้น/แรมกี่ค่ำ (โดยประมาณ) และวันจันทร์ดับ/เพ็ญถัดไป
- เลื่อนวัน/เดือน เลือกเวลา หรือกด ▶ เล่น ให้เวลาเดินเร็ว (1 ชั่วโมง ถึง 1 เดือน ต่อวินาที)

## เริ่มใช้งาน

ต้องมี Node.js 18 ขึ้นไป ไม่ต้องติดตั้งแพ็กเกจเพิ่ม

```bash
npm start   # เปิดที่ http://localhost:3000
npm test    # ทดสอบการคำนวณเทียบกับเวลาจาก USNO
```

หรือวางไฟล์ทั้งโฟลเดอร์บนเว็บโฮสต์แบบ static ใดก็ได้ (GitHub Pages ฯลฯ) เพราะเป็น HTML/JS ล้วน

## การคำนวณ

`js/astro.js` ใช้สูตรอย่างย่อจาก Jean Meeus, *Astronomical Algorithms* ตำแหน่งดวงอาทิตย์คลาด ~0.01° และดวงจันทร์ ~0.02°
เวลาวิษุวัต/อายัน และจันทร์ดับ/เพ็ญ จึงคลาดไม่กี่นาที ส่วน "ขึ้น/แรม ค่ำ" นับจากวันจันทร์เพ็ญ = ขึ้น 15 ค่ำ
ซึ่งอาจต่างจากปฏิทินจันทรคติไทยทางการได้ 1 วัน

แผนที่โลกจาก Natural Earth (สาธารณสมบัติ) แปลงเป็นตาราง 1° ไว้ใน `js/land.js`
