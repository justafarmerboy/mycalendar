# หน้าปัดปฏิทินฟ้า สำหรับ Amazfit T-Rex 3

หน้าปัด Zepp OS ที่ย่อฉากหลักของเว็บปฏิทินฟ้าลงบนจอกลม 480×480

- โลกอยู่ตรงกลาง แกนเอียงตามฤดูจริง (36 ภาพ ทุก 10° ของตำแหน่งดวงอาทิตย์) ดวงอาทิตย์อยู่ทางซ้าย
- ดวงจันทร์โคจรรอบโลกตามตำแหน่งจริง และแสดงข้างขึ้นข้างแรมตามที่เห็นจากโลก (30 ภาพ)
  ช่วงข้างแรมดวงจันทร์จะอ้อมไปอยู่หลังโลก
- เวลา (ใช้ตัวเลขของระบบ จึงแสดงต่อในโหมดหน้าจอเปิดค้าง/AOD ได้) วันที่แบบ พ.ศ.
- ขึ้น/แรมกี่ค่ำ และชื่อข้างขึ้นข้างแรม นับถอยหลังถึงวิษุวัต/อายันครั้งถัดไป
- ชีพจร ก้าวเดิน แบตเตอรี่
- คำนวณบนนาฬิกาทุกนาทีด้วยสูตรเดียวกับเว็บ (`shared/astro.js` เป็นสำเนาของ `../js/astro.js`)

รองรับ T-Rex 3, T-Rex 3 Pro 48mm และ T-Rex Ultra 2 (จอกลม 480×480 ทั้งหมด)

## ติดตั้งลงนาฬิกา

ทำบนคอมพิวเตอร์ (Windows/Mac) ครั้งแรกครั้งเดียว:

1. ติดตั้ง Node.js (LTS) จาก https://nodejs.org
2. ติดตั้งเครื่องมือ Zeus ของ Zepp: `npm i -g @zeppos/zeus-cli`
3. สมัครบัญชีนักพัฒนา Zepp (ฟรี) ที่ https://console.zepp.com
4. ในแอป Zepp บนมือถือ: โปรไฟล์ → การตั้งค่า → เกี่ยวกับ แล้วแตะโลโก้ Zepp 7 ครั้งติดกัน
   จนมีหน้าต่างเด้งขึ้น จะได้เมนู "โหมดนักพัฒนา" (Developer Mode)

ติดตั้งหน้าปัด:

```bash
cd watchface
zeus login      # เปิดเบราว์เซอร์ให้เข้าสู่ระบบบัญชีนักพัฒนา
zeus preview    # เลือก target แล้วจะได้ QR code
```

เปิดแอป Zepp → โปรไฟล์ → การตั้งค่า → โหมดนักพัฒนา → Scan แล้วสแกน QR code
หน้าปัดจะติดตั้งลงนาฬิกาและตั้งเป็นหน้าปัดปัจจุบัน

### ติดตั้งจากมือถือโดยไม่ใช้คอม (ทดลอง)

ไฟล์หน้าปัดที่ build แล้วอยู่บนเว็บที่ `/install/skycalendar-trex3.zip` และ QR code อยู่ที่ `/install/qr-trex3.png`
เปิดรูป QR บนจออื่น แล้วสแกนด้วยแอป Zepp → โหมดนักพัฒนา → Scan
QR นี้ใช้รูปแบบเดียวกับ `zeus preview --local` (`zpkd1://โฮสต์:พอร์ต/ไฟล์.zip`) ชี้ไปที่ TCP proxy ของ Railway
(`roundhouse.proxy.rlwy.net:38172` เป็น http ตรง เพราะโดเมนปกติของ Railway ส่งต่อไป https ซึ่งแอป Zepp ไม่ตาม)
เมื่อแก้หน้าปัด ให้ `zeus build` แล้วคัดลอกไฟล์ `.zpk` ใน `dist/*.zab` ไปทับ `install/skycalendar-trex3.zip`

ถ้า `zeus preview` แจ้งเรื่อง appId ให้สร้างโปรเจกต์หน้าปัดใหม่ใน https://console.zepp.com
แล้วเอา appId ที่ได้มาใส่ใน `app.json` (ช่อง `app.appId`)

## สิ่งที่ยังต้องเช็กบนนาฬิกาจริง

- ภาษาไทยบนนาฬิกา: ข้อความใช้ฟอนต์ของระบบ ถ้านาฬิกาแสดงไทยไม่ได้จะเห็นเป็นกล่องสี่เหลี่ยม
- โหมด AOD แสดงเฉพาะเวลาและวันที่ ภาพโลกกับดวงจันทร์จะปรากฏเมื่อยกข้อมือ

## พัฒนาต่อ

zeus build                                   # สร้างไฟล์ติดตั้ง dist/*.zab
node tools/render-assets.cjs [Sarabun.woff]  # วาดรูปใน assets/trex3/images ใหม่ (รันจากโฟลเดอร์ mycalendar)

(รันด้วย `npm test` ที่โฟลเดอร์ mycalendar) ซึ่งจำลองนาฬิกาด้วย hmUI/hmSensor ปลอม
